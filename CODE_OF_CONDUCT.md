# Code of Conduct

This is a single-maintainer fork. Be respectful and constructive in issues and pull
requests; anything else is moderated at the maintainer's discretion. There is no formal
enforcement ladder — the maintainer reserves the right to close, lock, or ignore
interactions that are abusive, harassing, or otherwise unwelcome.

For the upstream project's own community standards, see
[`anthropics/commerce-agents`](https://github.com/anthropics/commerce-agents).
